# my-portfolio
This is my personal website built using HTML and Tailwind.
This is my first website development project.
The website is all about me, my thoughts, and my interests.
I had both fun and challenges while creating this project.
I watched many YouTube tutorials to improve my HTML skills and learn more about web development.
The website includes a navigation bar that helps users move between different pages.
There are four pages on the website:
Main
Thoughts
About
Contact
Each page contains short and simple information about me.
The website is easy to navigate and use.
If you'd like to get in touch with me, you can find my contact information on the website.
